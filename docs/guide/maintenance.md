# 设置、计费、备份与迁移

本页覆盖控制台中的全局设置、模型价格管理、计划任务以及配置备份与跨平台渠道迁移。

## 全局设置导航

进入 **设置** 页面，顶部标签页按职责划分如下（所有配置键默认值见 [配置参考](../reference/configuration)）：

| 标签页 | 主要管理内容 |
| --- | --- |
| **常规** | 站点名称、自定义 Logo、界面主题/语言、系统与统计时区、管理员用户名与密码 |
| **网关** | 全局代理 URL、CORS 允许来源、全局上游请求头规则、全局参数覆盖规则、超时预算、请求体上限、正文日志开关与留存天数 |
| **隐私** | 规则隐私开关、检测类别（密钥/个人信息）、处置动作（`mask`/`warn`/`block`）、自定义词与正则、豁免词 |
| **故障转移** | 各类错误阈值与初始冷却时长、退避倍率与最大冷却、多 Key 限流升级、全冷却等待、故障亲和时长、健康分滑动窗口参数 |
| **网关密钥** | 外部客户端使用的 Key、可用模型组白名单、累计费用上限与到期时间 |
| **计划任务** | 查看与修改 6 个内置后台任务的调度频率或手动触发 |
| **备份与迁移** | 全量 JSON 导出/覆盖导入，以及从其他网关格式识别并迁移渠道 |

## 模型价格与计费管理

打开侧栏 **价格** 页面管理模型计费口径：

- **自动价格同步**：从 LiteLLM 公共价格元数据拉取最新单价（包含输入、图像输入、输出、缓存读取、缓存写入以及按张计费的图像模型价格）。
- **手动覆盖与恢复**：可为任意模型组填写手动价格；界面会明确标出手动覆盖项。点击 **恢复自动** 后，将在下次同步时重新按自动源刷新。
- **计费模式**：
  - `tokens`：按输入、图像输入、输出、缓存读/写 Token 分项核算（$/1M tokens）；
  - `non_tokens`：适用于纯图像生成/编辑等按张计费的模型（$/image）；
  - `free`：免费模型（费用记为 0）。
- **倍率叠加**：如果渠道凭证配置了 **Sub2API / NewAPI 倍率同步**，最终估算费用会乘以对应凭证的 `rate_multiplier`。

## 计划任务

![计划任务列表中的执行周期、状态、下次执行时间与操作](/images/scheduled-tasks.png)

在 **设置 → 计划任务**（或侧栏独立入口）中管理以下 6 个内置任务：

| 任务 ID | 名称 | 默认周期 | 用途说明 |
| --- | --- | --- | --- |
| `request_log_prune` | 请求日志清理 | 每 1 小时 | 按 `relay_log_keep_enabled` 与 `relay_log_keep_period` 删除过期请求日志 |
| `model_price_sync` | 模型价格同步 | 每 24 小时 | 从 LiteLLM 同步模型价格与上下文窗口元数据 |
| `request_log_stats_persist` | 请求日志统计落库 | 每 1 小时 | 将请求日志与多维归因统计增量持久化，降低大表聚合开销 |
| `version_check` | 版本检测 | 每 24 小时 | 读取文档站 [`version.txt`](https://dyedd.github.io/lens/version.txt) 检查最新正式 Release |
| `channel_model_sync` | 渠道模型同步 | 每 24 小时 | 为启用且支持目录拉取的渠道同步上游模型并自动重新归组 |
| `credential_rate_sync` | 凭据倍率同步 | 每 24 小时 | 刷新已配置 Sub2API 或 NewAPI 计费来源的凭证倍率 |

每个任务均支持切换 **按固定间隔** 或 **按星期/固定时间点** 调度、启停开关以及点击 **立即运行**。在多副本/多 worker 部署中，任务执行前会在数据库中申请租约锁（`lease_owner` / `lease_until`），防止多个实例重复执行同一任务。

## 备份与迁移

打开 **设置 → 备份与迁移**，页面分为 **全量备份恢复** 与 **其他平台渠道导入** 两个独立功能区。

![配置导出、可选日志和网关密钥，以及覆盖导入入口](/images/backups.png)

### Lens 全量导出与覆盖导入

1. **导出 JSON**：按需选择是否同时打包 **网关密钥** 与 **请求日志**（含归档统计）。
   - **安全提示**：即使不勾选网关密钥，导出文件依然包含上游站点凭证，请妥善加密或离线保存。
2. **导入并覆盖**：选择导出的 JSON 文件后，界面会先展示导入预览摘要；确认后执行覆盖写入。
   - **重要边界**：环境变量（`.env` 中的数据库地址、端口、`LENS_AUTH_SECRET_KEY`）不包含在 JSON 备份中；
   - **隐私清理**：如果当前实例或备份中启用了规则隐私，导出与导入过程都会自动对日志内容执行一次隐私清理，占位符无法还原成原文。
3. **跨数据库迁移（SQLite → PostgreSQL）**：先在旧库导出完整 JSON，修改 `LENS_DATABASE_URL` 启动新库并自动建表后，登录新实例界面执行导入覆盖。

### 从其他平台迁移渠道

在 **导入其他平台的渠道** 卡片中，直接拖入或选择外部平台导出的配置文件，Lens 会自动识别格式、解析为预览列表（展示识别到的站点数、Key 数、模型数及跳过提示），勾选需要导入的条目后点击 **导入所选渠道** 即可写入（重名站点会自动跳过）。

目前支持以下 6 种外部格式：

| 源平台 | 支持的文件格式与特征 |
| --- | --- |
| **Metapi** | 导出的 JSON 备份（含 `accounts.sites`） |
| **Sub2API** | 导出的 JSON 数据包（`sub2api-data` / `sub2api-bundle`） |
| **ccLoad** | 导出的 CSV 表格（含 `name`、`urls`、`models` 列） |
| **All API Hub** | 导出的 JSON 备份（含 `version`、`timestamp` 及 `accounts`/`apiCredentialProfiles`） |
| **Octopus** | 导出的 JSON 备份（含整数 `version`、`exported_at` 及 `channels`/`groups`） |
| **CLIProxyAPI** | `config.yaml` / `.yml`（识别 `openai-compatibility`、`claude-api-key`、`gemini-api-key` 等提供商节点） |

> [!TIP]
> 导入外部平台文件与全量配置恢复不同：它**只增量新增勾选的渠道**，不会覆盖你现有的其他站点、模型组、网关密钥或系统设置。
