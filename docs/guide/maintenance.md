# 设置、备份与维护

设置页集中管理账号、网关参数、故障转移、网关密钥、计划任务、插件和备份。

## 修改设置

![设置页面的分类导航、站点信息和账号选项](/images/settings.png)

- **常规**：站点名称、Logo、外观、时区和管理员账号。
- **网关**：代理、CORS、请求参数、Header、超时和日志留存。
- **故障转移**：冷却、退避、恢复等待与健康评分。
- **网关密钥**：客户端的访问权限、费用上限和有效期。

普通设置会自动保存；账号和密码按对应按钮确认。修改后等待保存完成，再刷新检查。各参数默认值见 [配置参考](../reference/configuration)。

## 备份与迁移

打开 **设置 → 备份与迁移**。

![配置导出、可选日志和网关密钥，以及覆盖导入入口](/images/backups.png)

**导出：**

1. 按需勾选包含请求日志和网关密钥。
2. 点击 **导出 JSON**。
3. 将备份保存在受限位置，并确认文件可以读取。

配置归档包含站点、组、设置、价格、计划任务和统计数据。站点配置本身含上游凭证；即使没有勾选“包含网关密钥”，备份文件仍需要按敏感配置保管。

**恢复或迁移：**

1. 先备份目标实例。
2. 选择要导入的 JSON 文件。
3. 确认目标后执行 **导入并覆盖**。
4. 检查渠道、模型组、Key 权限和计划任务，再做一次客户端调用。

导入会覆盖配置。插件源文件和进程环境变量不在配置归档中，应单独备份插件目录和部署配置。

从 SQLite 迁移到 PostgreSQL 时，先导出配置；修改数据库连接并完成新库迁移后，再通过界面导入。需要保留日志和网关 Key 时，在导出时选中相应选项。

页面下方的 **导入其他平台的渠道** 用于解析其他平台的备份。先检查预览结果，再确认接入；它与 Lens 全量配置覆盖导入的用途不同。

## 计划任务

![计划任务列表中的执行周期、状态、下次执行时间与操作](/images/scheduled-tasks.png)

在 **设置 → 计划任务** 中查看：

| 任务 | 用途 |
| --- | --- |
| 渠道模型同步 | 拉取上游模型，按每把 Key 的规则更新模型并重新归组 |
| 模型价格同步 | 从 LiteLLM 更新价格元数据 |
| 凭据倍率同步 | 更新已配置的 Sub2API / NewAPI 倍率信息 |
| 请求日志清理 | 按留存配置删除过期日志 |
| 请求日志统计归档 | 将请求统计持久化 |
| 版本检测 | 从文档站的 `version.txt` 检查已发布版本 |

按需启停任务或修改时间计划。手动运行后查看执行结果；同步失败时先解决地址、凭证或网络问题。模型同步可能移除上游已下线的模型，执行前检查过滤规则。

版本检测读取 <https://dyedd.github.io/lens/version.txt>，检测到更新后可打开对应的 GitHub Release。检测失败时保留上一次成功结果；先确认文档站可访问，再重新运行任务。

## 管理价格

在侧栏打开 **价格**。可以同步公共价格数据，或为实际使用的模型填写手动价格。手动覆盖和自动价格的区别会显示在界面中；恢复自动价格后重新按同步来源更新。

Token 模型按输入、输出和缓存用量计费；图像模型可按张计费。凭证倍率和模型组价格配置也会影响最终统计，排查时以请求详情记录的实际模型和费用为准。

## 安装与启停插件

1. 把插件文件放入 `data/plugins/<plugin_id>/plugin.py`，或放成单个 `.py` 文件。
2. 打开 **设置 → 插件**，等待自动发现，或点击重新扫描。
3. 查看插件状态和错误信息，按需启停并填写设置。
4. 运行一次相关请求，检查插件调用统计。

![已加载插件的扩展点、状态和调用统计](/images/plugins.png)

Docker 的 `data/` 已挂载到容器 `/app/data`，插件从 `/app/data/plugins` 加载。源码和设置更新支持热加载；进行中的请求继续使用开始时的插件版本。

插件通过文件安装，界面负责启停、配置和重扫。自定义插件的完整契约见 [插件开发](../development/plugins)。

## 升级前检查

保留配置备份、部署配置和插件源文件；需要完整回退能力时，同时备份数据库。更新镜像后的迁移步骤见 [快速开始](./quick-start#升级)。

应用正式发版后会刷新文档站的版本文件。文档内容也可以独立发布，GitHub Pages 的资源不会进入应用 Docker 镜像。
